Come interpretarlo

Se l'ultimo ordine mostra almeno un invio riuscito, il percorso server → provider Web Push ha funzionato. Se il test background arriva dopo aver chiuso la pagina, anche il dispositivo/browser riceve correttamente in background. Se il server invia ma non compare nulla, controlla le notifiche del sistema operativo e che il browser/PWA non sia stato force-stop. Il suono forte della pagina Orders resta separato e richiede pagina aperta.
